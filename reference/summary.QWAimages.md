# Print summary of a QWAimages object

Displays a compact overview of a
[QWAimages](https://tria-db.github.io/rxs2tria/reference/QWAimages.md)
object: the ROXAS software version, dimensions, and coverage
(woodpieces, slides, images, year range).

## Usage

``` r
# S3 method for class 'QWAimages'
print(x, ...)

# S3 method for class 'QWAimages'
summary(object, ...)
```

## Arguments

- x:

  A `QWAimages` object.

- ...:

  Further arguments (currently unused).

- object:

  A `QWAimages` object.

## Value

`object`, invisibly.
