# Read a QWAmetadata object from a JSON file

Read a QWAmetadata object from a JSON file

## Usage

``` r
read_QWAmetadata(file)
```

## Arguments

- file:

  Path to a `.json` or `.json.gz` file of QWAmetadata.

## Value

A
[QWAmetadata](https://tria-db.github.io/rxs2tria/reference/QWAmetadata.md)
object.
