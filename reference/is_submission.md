# Is a QWAmetadata object from submission files?

Is a QWAmetadata object from submission files?

## Usage

``` r
is_submission(x)
```

## Arguments

- x:

  A
  [QWAmetadata](https://tria-db.github.io/rxs2tria/reference/QWAmetadata.md)
  object.

## Value

`TRUE` for submission files, `FALSE` for TRIA dataset files (see
[`QWAmetadata()`](https://tria-db.github.io/rxs2tria/reference/QWAmetadata.md)).
